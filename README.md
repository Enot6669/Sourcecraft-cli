# SourceCraft Studio

Desktop GUI for SourceCraft CLI on Windows.

## Status
Early prototype (v0.1.0). The application is built with Electron, React and Vite. Windows installer and real CLI integration are not yet verified.

## Planned features
Project explorer, code editor, AI chat, CLI integration, terminal, Git changes, session history and Windows builds.

## Local development
```powershell
npm install
npm run desktop:dev
```

## Tests
```powershell
npm test
```

See `tests/SMOKE_TEST.md` for manual acceptance checks.
